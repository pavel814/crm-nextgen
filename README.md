# CRM NextGen

Ты работаешь над crm.
На первых четырех скриншотах старые разделы "Команда", "Рабочие часы" и "Настройки".
На 5,6, 7 и 8 скриншотах новый дизайн нашей crm.
Твоя задача переделать старые разделы так, что бы наша crm порвала рынок.
Стильная, современная и функциональная.
Все кнопки должны быть рабочими.
